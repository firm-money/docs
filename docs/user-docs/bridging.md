# Bridging to Status Network

This guide explains how to bridge assets to [Status Network](https://status.network/) to use with Firm Money.

## Getting Started with Status Network

Status Network is an Ethereum L2 chain purpose-built for community-driven applications. Visit [status.network](https://status.network/) for the latest bridging guides and supported bridges.

## After Bridging

Once your assets arrive on Status Network:

1. **Start Using Firm Money**:
   - Visit the Firm Money app
   - Connect your wallet
   - Use your bridged assets as collateral to mint USF
   - Deposit USF in stability pools to earn yield

## Need Help?

- Visit [Status Network](https://status.network/) for bridge information
- Check our [GitHub](https://github.com/firm-money/firm) for technical questions
